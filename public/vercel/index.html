OpenSI for Vercel

Connect your own Vercel account to OpenSI and deploy projects from the OpenSI workspace. Each OpenSI user authorizes their own Vercel team or personal account. You do not need to paste a Vercel API token into OpenSI.

How it works

  1. Sign in to OpenSI with Google.
  2. Open Ulanishlar → Deploy va API and choose Vercel bilan ulash.
  3. Review the requested Vercel permissions and authorize the integration.
  4. Ask the agent to build and deploy a project. OpenSI sends that project's files to your connected Vercel account and shows build status and the deployment URL.

The integration requests permission to create and read projects and deployments, upload deployment files, and manage integration-owned project environment variables. Vercel may apply account limits and charges under your Vercel plan. Disconnect the account from OpenSI's connections page when you no longer need it.
