# Gemini video in OpenSI

OpenSI Media studiyasida video uchun standart manba **Google Flow hisob krediti**. Video API modeli ulangan taqdirda ham u avtomatik tanlanmaydi. Serverda `OPENSI_VIDEO_API_ENABLED=false` standart holat: video modeli API katalogidan yashiriladi, yangi video va sahnali video so‘rovlari rad etiladi. API rasm va ovoz uchun alohida ishlashi mumkin.

Faqat alohida pullik Gemini video API oqimi kerak bo‘lsa, administrator `OPENSI_VIDEO_API_ENABLED=true` ni serverda ongli ravishda yoqishi mumkin. Quyidagi API texnik tafsilotlari shu ixtiyoriy rejimga tegishli. Google Flow login yoki krediti Gemini Developer API kaliti o‘rnini bosmaydi; API bilan video yaratish Google AI Studio hisob-kitobiga tushadi.

**Google Flow hisob krediti:** Media studiyadagi "Google Flow · hisob krediti" rejimi foydalanuvchini rasmiy Flow saytiga olib boradi. U yerda foydalanuvchi o‘z Google hisobini tanlaydi va Flow kreditlari bilan video yaratadi. Tayyor MP4 avval kompyuter/telefonda mahalliy ko‘riladi; faqat "Kutubxonaga saqlash" bosilganda OpenSI serveriga yuklanadi. Kutubxonadan preview va yuklab olish mumkin. Flow login sessiyasi, kreditlari va shaxsiy paroli OpenSI serveriga berilmaydi. Hozir bu rejim server tomonidan avtomatik video generatsiya qilish API’si emas; avtomatik API oqimi yuqoridagi alohida pullik Gemini kalitiga bog‘liq.

**Flow kreditida oldingi klipdan davom etish:** Media studiya kutubxonadagi istalgan MP4ni, jumladan Flow’dan qayta yuklangan klipni, tanlaydi va brauzerning o‘zida oxirgi kadrini PNG sifatida chiqaradi. Foydalanuvchi shu PNGni Google Flow’da yangi videoning boshlang‘ich kadri qilib biriktiradi, keyingi sahna matnini ko‘chiradi va tayyor MP4ni OpenSI kutubxonasiga qaytarib montajga ulaydi. Saqlangan klipni navbatdagi sahna uchun yana tanlash mumkin. Gemini Omni videolari uchun Flow ichidagi native “Extend” funksiyasi hozir mavjud emas; u faqat Veo videolarida ishlaydi. Shuning uchun bu oqim yangi sahna yaratish va montaj qilishdir, mavjud Gemini videosini Flow ichida o‘sha interaction ID bilan uzaytirish emas. Rasmiy qoida: https://support.google.com/flow/answer/16935718?hl=en va https://support.google.com/flow/answer/16352836?hl=en.

**VeoFlowAPI hisob krediti:** Media studiyadagi "VeoFlowAPI · hisob krediti" rejimi promptni tayyorlab, foydalanuvchini https://veoflowapi.com/omni manzilidagi Omni Studio’ga olib boradi. Video shu saytdagi hisob kreditlaridan yaratiladi; tayyor MP4ni OpenSI’ga olib kirib, boshqa kliplar bilan montaj qilish mumkin. VeoFlowAPI hisobining paroli yoki brauzer sessiyasi OpenSI serverida saqlanmaydi. Tekshirilgan boshqaruv panelida Omni Studio va Google Flow uchun Chrome kengaytmasi bor, lekin serverdan chaqiriladigan ommaviy video API kaliti yoki hujjatlashtirilgan endpoint ko‘rsatilmagan. Shu sababli bu yo‘lni Gemini API bilan avtomatik fallback yoki bevosita API integratsiyasi deb belgilamang. Sayt rasmiy yo‘riqnomasi: https://youtu.be/z0oGgYLtcrc. Rasmiy API taqdim etilsa, alohida server adapteri bilan integratsiya qilish mumkin.

**30 soniyagacha montaj:** Flow yoki VeoFlowAPI’dan 2–6 ta MP4 klipni olib, Media studiyada tartiblang yoki avval kutubxonaga saqlangan MP4larni tanlang. OpenSI har bir klipning haqiqiy davomiyligini FFprobe bilan tekshiradi, kadr o‘lchami va tezligini bir xil qiladi, 0.35 soniyalik video/ovoz o‘tishlari bilan H.264/AAC MP4ga yig‘adi. Umumiy video 30 soniyadan oshmaydi; kerak bo‘lsa faqat oxirgi klip qisqartiriladi va u kamida 1.5 soniya ko‘rinishi shart. Manbalar kutubxonada qoladi; tayyor faylni preview qilib yuklab olish mumkin. Bu montaj video xizmatlarining kreditini sarflamaydi. Sahnalar bir-biridan juda farq qilsa o‘tish butunlay bilinmaydi deb kafolat berilmaydi: bir xil qahramon, joy, yorug‘lik, kamera harakati va tovush davomiyligi bilan kliplar tayyorlang. Flow ichidagi "Extend" va Gemini Omni Flash API’dagi oldingi interaction ID bilan davom ettirish ikki alohida xizmat va hisob-kitob oqimidir. Rasmiy ma’lumot: https://support.google.com/flow/answer/16935718?co=GENIE.Platform%3DDesktop&hl=en va https://ai.google.dev/gemini-api/docs/omni#video-extension.

**Reference kadr va qo‘lda montaj:** Media studiyada bir xil qahramon/mahsulot tavsifidan Gemini image API orqali rasm yarating yoki o‘zingizning PNG/JPEG/WebP rasmingizni kiriting. Rasm shaxsiy kutubxonaga saqlanadi. API video rejimida tanlangan bitta reference rasm har bir yangi so‘rovga manba sifatida beriladi; mavjud videoni `previousJobId` bilan davom ettirganda esa avvalgi video konteksti ishlatiladi. Flow yoki VeoFlowAPI hisob krediti rejimida rasmni yuklab, o‘sha saytning reference/ingredient maydoniga **foydalanuvchi o‘zi** kiritadi; OpenSI bu tashqi brauzer sessiyalariga faylni avtomatik bermaydi. Bir xil rasm natijani yaqinlashtiradi, aynan bir xil yuz/kadrni kafolatlamaydi. Rasm yaratish faqat ulangan Gemini API balansidan sarflanadi; Flow hisobidan rasm yaratish uchun Flow saytining o‘zidan foydalaning.

Montajning avtomatik rejimi avvalgidek 2–6 klipni 0.35 soniyalik yumshoq o‘tishlar bilan birlashtiradi. Qo‘lda rejim 1–6 MP4 uchun boshlanish va tugash vaqtini, klip ovozini o‘chirishni, tartibni va yumshoq yoki kesib o‘tishni tanlashga imkon beradi. Har bir kesim kamida 1.5 soniya; qo‘lda tanlangan umumiy natija 30 soniyadan oshsa avtomatik qisqartirilmaydi. Natijani preview/yuklab olish yoki kutubxonadan yana montajga qaytarib tahrirlash mumkin. Flow loyihasidagi videolarni OpenSI montajiga qo‘shish uchun MP4 sifatida yuklab olish kerak; rasmiy Flow yordam sahifasi uning Scenebuilder ichida ham kliplarni tartiblash, kesish va yuklab olishni ta’riflaydi: https://support.google.com/flow/answer/16935718?hl=en.

Google narxlar sahifasiga ko‘ra, 720p chiqish taxminan $0.10/soniya. Tarif, sifat va davomiylik sarfni o‘zgartiradi; yaratilgan har bir video hisob egasining Google balansidan yechiladi. API provayderi barcha OpenSI foydalanuvchilariga ochilsa, ular ham shu balansdan foydalanadi. Shuning uchun ommaviy ulashdan oldin xarajat chegarasini Google AI Studio billing sozlamasida belgilang.

Media studiyada ssenariy va ekrandagi matn, uslub, 16:9 yoki 9:16, hamda sifat tanlanadi. Foydalanuvchi manba rasmni jonlantirishi, 10 soniyagacha MP4 videoni tahrirlashi yoki oldingi yaratilgan videoni yangi ko‘rsatma bilan davom ettirishi mumkin. Dars videosi tugmasi 8 soniyalik boshlovchi va yon panel uchun uslub namunasini kiritadi. Bu namuna vizual yo‘nalishdir; model aynan bir xil kadr, yozuv va talaffuzni kafolatlamaydi.

Google cheklovi: yuklangan videodagi gapirayotgan odamning nutqini yangi dialog bilan uzaytirib bo‘lmaydi. Shunga o‘xshash yangi o‘quv videosi uchun matndan yaratish va dars uslubi presetidan foydalaning.

Natija Google Interactions API orqali so‘raladi. URI bilan qaytsa, OpenSI faqat o‘sha API originidagi fayl identifikatorini qabul qiladi, holatini kuzatadi, MP4 imzosini tekshiradi va 48 MB gacha faylni shaxsiy kutubxonaga saqlaydi. API kaliti serverda shifrlangan; brauzerga yuborilmaydi. Video natijasi media vazifasida preview va yuklab olish havolasi bilan chiqadi. Model xato yoki bo‘sh natija qaytarsa, vazifa bajarilgan deb ko‘rsatilmaydi.

Oldingi Gemini Omni videosini davom ettirishda `previous_interaction_id` va yangi sahna matni yuboriladi. `video_config.task=extend` majburan qo‘yilmaydi: bu qat’iy rejim ko‘p bosqichli matn so‘rovini `Only user input is allowed when video task is set` xatosi bilan rad qilishi mumkin. Interaction saqlanadi (`store=true`), shuning uchun keyingi sahna o‘sha video holatidan davom etadi.

Google kunlik video chegarasi HTTP 429 bilan tugasa, Media studiyadan bevosita yuborilgan so‘rov asl oldingi video ID va yangi sahna matni bilan saqlanadi. Google qayta urinish muddati ko‘rsatiladi; server muddat kelganda avtomatik qayta ishlaydi va qayta ishga tushsa ham navbatni saqlaydi. Uch marta 429 takrorlansa vazifa aniq xato bilan to‘xtaydi. Kutayotgan vazifani foydalanuvchi istalgan payt to‘xtata oladi. Avtomatik ko‘p sahnali loyiha bu navbatga qo‘shilmaydi; u o‘zining davom ettirish boshqaruvidan foydalanadi.

Hozirgi API ulanishi Omni Flash oqimiga tegishli. Flow hisob krediti va OpenSI MP4 montaji alohida oqimlardir.
