# ChatGPT dot → OpenSI projects

OpenSI exposes `https://<OpenSI host>/mcp` as a streamable HTTP MCP server. The user adds it in ChatGPT Plugins as a custom MCP server with OAuth authentication, installs the resulting private plugin, and lets their dot use it. This connects the user's actual dot to OpenSI; it does not copy a dot or treat the existing ChatGPT model provider as dot access.

The OAuth authorization page requires the user's OpenSI Google session and a separate project-access consent. Access tokens expire after one hour, refresh tokens after 30 days, and only hashed tokens are stored. OpenSI → Ulanishlar → ChatGPT dot revokes all grants for the signed-in user. Disabled accounts cannot use the MCP server. The MCP server accepts bearer tokens only, not browser cookies. No ChatGPT password, Codex token, or model credentials are required for this connection.

Tools: account profile, project list/details, visible file list, short text-file reads, task status, and (with `projects:write`) start/resume/cancel tasks. Every project and task lookup is scoped to the consenting OpenSI user. Starting a task uses OpenSI's automatic model route and existing project environment; local projects require the owner's connector to be online. The tool returns a run ID and the dot must poll status before claiming completion. OpenSI's existing task approvals and external account restrictions still apply.

Manual connection: ChatGPT Plugins → Add custom MCP server → name `OpenSI Projects` → Server URL `https://opensi.23-252-124-21.sslip.io/mcp` → OAuth → create and install privately. On the OpenSI consent page, sign in with the desired Google account and approve. Ask dot to list OpenSI projects, open one, and start a small task. Verify status in both dot and OpenSI. The ChatGPT plugin installation and real dot tool use must be checked in the owner's ChatGPT account; local MCP tests alone do not prove that final browser/account link.

On phone or desktop, open ChatGPT under the connected ChatGPT account, select or mention `@OpenSI Projects` in a conversation, and send the task there. OpenSI → Ulanishlar → ChatGPT dot provides a direct ChatGPT chat link. The same page also has an OpenSI task form: it starts an OpenSI automatic agent in a new cloud project or an existing selected project and opens the live project conversation. That form uses OpenSI's model routing; an MCP server is an inbound tool for ChatGPT, so the form must not be labeled as a direct call into the ChatGPT dot session. An offline personal computer cannot execute local project commands, while the separate hosted Antigravity provider remains available from phone when its server connector is online.
